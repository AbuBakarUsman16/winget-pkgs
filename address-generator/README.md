# StreetSample — US Address Generator

A single-file static website (`index.html`) that generates realistic US addresses for form testing, QA, and demos.

## Features
- State / city filters (50 states + DC) with real city ZIP ranges and area codes
- House-number preference (any, 1–3 digits, 4–5 digits), optional apartment/suite, ZIP+4
- Mailing-label preview with a POSTNET barcode for the ZIP
- Fake profile: name, gender, birthday, age, phone (fictional 555-01xx), email (@example.com), username, occupation
- Copy buttons per field, copy as JSON, OpenStreetMap / Google Maps links
- Bulk generation (5–50 rows) with Copy CSV / Copy JSON
- Recent history saved in the browser, light and dark themes, mobile layout
- Deep link to a state with `#TX`, `#CA`, etc.

## Run
Open `index.html` in a browser, or host it on any static host (GitHub Pages, Netlify, Vercel).

For testing only — not for fraud, impersonation, or bypassing verification.
